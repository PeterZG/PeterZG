## About

Hi, I'm **Weihou** — I also go by **Peter Benjamin Parker** online.

I started out studying architecture before moving into computer science. These days I mainly work on **full-stack applications**, with a stronger interest in the backend side: APIs, databases, data flow and system integration.

I'm also interested in **AI and human–computer interaction**, especially what happens when AI becomes part of something people actually use.
